# Da fare

- **Statistiche d'uso**: riepiloghi su run, tempi e token, per progetto e per periodo.
- **Reasoning e modello impostabili**: sceglierli anche dall'utente (composer o opzioni del
  progetto), non solo nei passi agent del workflow (`effort`/`model`).
- **Cambio della modalità durante un task**: vale dal prossimo gate o domanda, senza pausa;
  serve un messaggio server → runner.
- **Modifiche non salvate ai workflow**: oggi restano solo in memoria.
- **App desktop Neutralino**: servizio Node (prerequisito) avviato con l'exe, dati su file al
  posto di Postgres, server e runner in un solo processo, aggiornamento automatico.
